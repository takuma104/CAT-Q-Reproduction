# CAT-Q 再現実験レポート (Qwen3-0.6B / RTX 5090 x1)

対象論文: CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs (arXiv 2606.26650, docs/paper.md)

## 実験設定

- モデル: Qwen3-0.6B(論文の最小モデルは 1.7B。まずパイプライン確立のため 0.6B で実施)
- 量子化: W1.58A16(重みのみ三値化、group size 128、embedding / lm_head / norm は FP のまま)
- キャリブレーション: C4 から 512 サンプル × 2048 トークン、60 エポック/窓、AdamW lr=1e-3 線形減衰、バッチ 3
- ハイパラ: Δ₀=0.5, s₀=30, γ=0.8(論文 Table A 準拠)、ウィンドウ l=2 / ストライド 1(SliderQuant のデフォルト値は論文から読み取れないため独自設定)
- 評価: lm-evaluation-harness 0.4.12、zero-shot acc (%)
- 環境: RTX 5090 32GB ×1、torch 2.12.1+cu130、transformers 5.12.1

## 結果

zero-shot acc (%)。RTN は学習なしの静的 absmean 三値化(論文の SA ベースライン相当、group size 128)。

### 所見

- CAT-Q は PIQA (+5.7pt) と ARC-e (+6.1pt) でランダムを明確に上回るが、HellaSwag / ARC-c はランダム水準まで低下した。平均低下幅は −14.1pt。
- 論文の低下幅はモデルサイズに対して単調に拡大する(32B −5.2 → 14B −9.1 → 8B −9.8 → 4B −11.2 → 1.7B −10.4)。0.6B で −14pt はこの傾向の自然な外挿の範囲内であり、実装の不具合を示すものではないと判断している。
- Qwen3-0.6B は FP でも avg 50.69 と、論文の Qwen3-1.7B 量子化後(51.01)と同水準しかなく、三値化に耐える冗長性が乏しい。特に HellaSwag は FP 37.54 とランダム(25)との差が小さく、量子化劣化ですぐ床に張り付く。
- 量子化時間は 79.2 分(RTX 5090 ×1)。論文報告の「1.7B〜8B で 1 時間〜/8×A100」とオーダーで整合する。
- 学習の寄与は内部指標では明確(三値重みの zero 率が初期値 0.32 → 0.42 に移動、窓ごとの出力再構成誤差は hard-init 比 2.3〜346 倍改善)。一方、評価スコアでは RTN 比 avg +0.85pt(ARC-e では +5.5pt)にとどまる。0.6B ではモデルが崩壊する領域にあり、再構成誤差の改善がスコアに転化しにくい。32 サンプルの予備ラン(ステップ数 1/16)では RTN との差が皆無だったため、キャリブレーション量は効いている(論文 Table 11 の傾向と整合)。

## 実装で解釈が必要だった点

論文に明記がなく、再現実装で解釈・裁量した点(詳細は docs/plans/catq-reproduction-plan.md):

1. **スライディングウィンドウの詳細**: 「SliderQuant のデフォルトに従う」とのみ記載。l=2 / ストライド 1、窓の先頭層のみ確定して 1 層スライド、後続層の学習因子はウォームスタート、と解釈。
2. **ハード段階の勾配**: 「第 1 段階最後の反復の勾配を利用」→ f(·; s₀, Δ) を backward の代理関数とする STE として実装。
3. **60 エポックの単位**: 窓ごとと解釈(全体で 60 だと論文報告の量子化時間 1〜60h/8×A100 と矛盾)。
4. **ターゲットの定義**: Eq.7 は両項に同一の X を使うため、量子化済み上流の出力 X に対する FP 窓出力をターゲットとした(GPTQ/OmniQuant 系の慣行と同じ)。

## 診断で得た知見

- **静的 absmean 三値化(SA 相当)は第 1 デコーダ層の出力で相対誤差 84%** に達し、モデルは崩壊する。これは論文 Table 5 の SA ベースライン(Qwen3-4B ですら avg 40.16 ≒ ランダム水準)と整合する。
- **ST の損失曲線は「増加しながら収束」する**(論文 Appendix D の記述どおり)。ソフト段階初期は恒等写像に近く損失がほぼ 0 のため、エポック 1 との比較ではなく「学習前のハード三値化損失 (hard-init)」との比較が正しい健全性指標。
- 窓単位の出力再構成誤差は、最適化により hard-init 比で一貫して 3〜7 倍改善する。
- lr=1e-3(論文設定)は 32 サンプル(660 step/窓)では未収束。512 サンプル(10,260 step/窓)で到達可能な floor(第 1 窓で相対誤差 ≈0.32)にほぼ届く。

## 再現性についての考察

0.6B での結果は論文の主張を直接検証するものではない(論文の最小モデルは 1.7B)。パイプラインの実装・実行時間・内部指標(hard-init 損失比の改善、ST の損失曲線形状)は論文の記述と整合しており、実装は健全と判断している。

論文との直接比較には **Qwen3-1.7B**(論文 Table 1: W1.58A16 avg 51.01)での実行が必要。RTX 5090 ×1 で推定 3〜4 時間、メモリは十分収まる。この結果が avg 45〜51 程度に達すれば再現成功、0.6B 同様の崩壊(〜40)なら実装の見直し(特にウィンドウ設定・ターゲット定義の解釈)が必要になる。

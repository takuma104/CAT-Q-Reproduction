# CAT-Q 再現実験レポート (Qwen3-0.6B / 1.7B, RTX 5090 x1)

対象論文: CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs (arXiv 2606.26650, docs/paper.md)

## 実験設定

- モデル: Qwen3-0.6B(パイプライン確立用)、Qwen3-1.7B(論文 Table 1 との直接比較用)
- 量子化: W1.58A16(重みのみ三値化、group size 128、embedding / lm_head / norm は FP のまま)
- キャリブレーション: C4 から 512 サンプル × 2048 トークン、60 エポック/窓、AdamW lr=1e-3 線形減衰、バッチ 3
- ハイパラ: Δ₀=0.5, s₀=30, γ=0.8(論文 Table A 準拠)、ウィンドウ l=2 / ストライド 1(SliderQuant のデフォルト値は論文から読み取れないため独自設定)
- 評価: lm-evaluation-harness 0.4.12、zero-shot
- 環境: RTX 5090 32GB ×1、torch 2.12.1+cu130、transformers 5.12.1

## 結果

### 所見

- 0.6B は FP でも avg 52.29 と論文の 1.7B 量子化後(51.01)と同水準しかなく、三値化に耐える冗長性が乏しい。CAT-Q でほぼランダム水準まで低下するのはスケール的に不思議ではない。
- 1.7B では 0.6B より明確に良い(avg 39.74 vs 37.30、生成品質も質的に改善)が、論文の回復幅には届かない。
- 学習の寄与は内部指標では明確: 三値重みの zero 率が初期値 0.32 → 0.40 台に移動し、窓ごとの出力再構成誤差は hard-init(学習前ハード三値化)比で一貫して 2〜300 倍台の改善。32 サンプルの予備ラン(ステップ数 1/16)では RTN と差が出なかったため、キャリブレーション量も効いている(論文 Table 11 の傾向と整合)。
- 量子化時間(0.6B: 79 分、1.7B: 180 分 / RTX 5090 ×1)は論文報告とオーダー整合。

## 実装で解釈が必要だった点

論文に明記がなく、再現実装で解釈・裁量した点(詳細は docs/plans/catq-reproduction-plan.md):

1. **スライディングウィンドウの詳細**: 「SliderQuant のデフォルトに従う」とのみ記載。l=2 / ストライド 1、窓の先頭層のみ確定して 1 層スライド、後続層の学習因子はウォームスタート、と解釈。
2. **ハード段階の勾配**: 「第 1 段階最後の反復の勾配を利用」→ f(·; s₀, Δ) を backward の代理関数とする STE として実装。
3. **60 エポックの単位**: 窓ごとと解釈(全体で 60 だと論文報告の量子化時間 1〜60h/8×A100 と矛盾)。
4. **ターゲットの定義**: Eq.7 は両項に同一の X を使うため、量子化済み上流の出力 X に対する FP 窓出力をターゲットとした(GPTQ/OmniQuant 系の慣行と同じ)。

## 診断で得た知見

- **静的 absmean 三値化(SA 相当)は第 1 デコーダ層の出力で相対誤差 84%** に達し、モデルは崩壊する。これは論文 Table 5 の SA ベースライン(Qwen3-4B ですら avg 40.16 ≒ ランダム水準)と整合する。
- **ST の損失曲線は「増加しながら収束」する**(論文 Appendix D の記述どおり)。ソフト段階初期は恒等写像に近く損失がほぼ 0 のため、エポック 1 との比較ではなく hard-init 損失との比較が正しい健全性指標。
- lr=1e-3(論文設定)は 32 サンプル(660 step/窓)では未収束。512 サンプル(10,260 step/窓)で到達可能な floor(第 1 窓で相対誤差 ≈0.32)にほぼ届く。
- 3 因子/128 重みグループというパラメタ化の表現力の下では、第 1 窓の出力相対誤差の floor は ≈0.32(LR・エポックを増やしても改善しない)。論文の回復幅を出すには、この floor をさらに下げる別の機構が必要な可能性が高い(下記)。

## 第2フェーズ: SliderQuant 論文 (docs/papers/slider-quant-paper.md) を反映した改善

初版レポート時点で最有力だった「SliderQuant フレームワークの中身が不明」という仮説は、実際の SliderQuant 論文の入手により解消した。判明した内容:

- **チャネル単位スケーリング (CS)**: X⊘α / W⊙α、OmniQuant 流、LR 1e-3、init 1
- **LoRA (r=4)** を全 linear に適用: W̃ = W⊙α + AB、LR 1e-4、量子化前の重みに吸収
- **インターレイヤースケジュール**: 浅い 4 層は拡張窓 PESW(第 1 層アンカー)、中間層は固定窓 {s=2, i=1}(初版の推測と一致)、深い 4 層は収縮窓 PCSW(最終層アンカー)、境界は 1 層オーバーラップ
- エポック 60 (W2A16)・スケーリング LR 1e-3 は CAT-Q Table A と一致(整合確認)
- イントラレイヤースライディング (γ=0.5, N=2) は ST スケジュールとの結合が不明なため未実装

### 統合で判明した 2 つの落とし穴(いずれも論文 2 本からは読み取れない結合部の仕様)

1. **ST の再アニール破壊**: ウォームスタートした層を窓ごとに t=0 から再アニールすると、ハード段階の解がソフト段階で破壊される(PESW アンカー層は 4 回リセットされ、C4-val PPL が 375 → 62 万に爆発)。→ **t は層の参加期間全体で単調に進め、最終参加窓で t=1 に到達**させる方式に修正。
2. **CS は三値量子化で有害**: lifetime annealing 修正後も CS 有効時は PPL 44 万と崩壊。アブレーション(下表)で CS が原因と特定。事前正規化された重み分布をグループ三値化する CAT-Q の LM と、自由なチャネルスケーリングが干渉すると考えられる。CAT-Q 論文の「SliderQuant のデフォルトに従う」は**ウィンドウサイズの選択**についての記述であり、CS の使用までは含意しない可能性が高い。

### アブレーション (0.6B, 512×60, C4-val PPL; FP=21.97)

| 構成 | PPL |
| --- | --- |
| v1: 固定窓・CS/LoRA なし (初版) | 375 |
| フル SQ (CS+LoRA+スケジュール) + MSE 損失 | 437,287 |
| フル SQ + token-RMS 正規化損失 | 502,684 |
| **SQ − CS (LoRA+スケジュール) + MSE 損失 = v2** | **275** |
| SQ − CS + token-RMS 正規化損失 | 559 |

副次的知見: 窓出力の生 MSE を最小化すると massive-activation チャネルの振幅が系統的に縮み(回帰希釈)、直後の RMSNorm がスケール不足を方向誤差に変換・増幅する(pre-norm 相対誤差 0.75 でも post-norm 1.52、top-1 一致 3%)。ただし token-RMS 正規化損失での対策は逆効果で、素の MSE が最良だった。

## 第3フェーズ: リファレンス実装 (docs/reference_impl/) を反映した v3

SliderQuant / OmniQuant のリファレンス実装の入手により、論文からは読み取れなかったフレームワークの実体が判明した:

- **二重ストリーム学習**(最重要): FP ストリームと量子化ストリームを別々に前進させ、損失は「量子化ストリームを入力された student が FP ストリームの教師出力を再現する」形(`use_base_loss="last"`)。窓ごとに蓄積誤差を能動的に補正する。v2 までの実装(同一 X で局所忠実度のみ)では深層の誤差蓄積が抑えられなかった。
- **イントラレイヤースライディングの実体**: `quant_rate` ∈ {0.5, 1.0} の 2 パスで全窓スケジュールを 2 周(各重みの先頭 50% の入力チャネルのみ量子化 → 全量子化)。エポックは 60÷2=30/窓。
- **窓は num_layer=4 / stride=2 / fill=4**(W2A16 config。論文 Table A の s=2,i=1 とは異なる)。
- **途中確定なし**: 全層を fake-quant のまま最後まで保持し、終了時に一括焼き込み。
- **W2A16 は `quant_mode: lora_only`、`scale_lr: 0`** — 重みのみ量子化ではチャネルスケーリング不使用。**フェーズ2のアブレーション(CS有害)と一致**。
- lora_lr 5e-4、LR はバッチサイズ倍にスケール、weight_decay 0。

実装上の追加対応: 1.7B で OOM したため、bf16 重み保持・グループ単位マスク・ストリームのインプレース前進で約 10GB 削減。

## 残ギャップ (−7.6pt) の原因仮説

フレームワーク側の主要素(二重ストリーム・2パス・窓スケジュール・LoRA)はリファレンス実装どおりに揃えたため、残るギャップは CAT-Q 固有の結合部か細部にあると考えられる:

1. **ST スケジュールとフレームワークの結合**: 本実装は t を「層の参加期間全体」(2パス×全参加窓)で単調に進める独自設計。CAT-Q が実際に 2 パス構造と ST(γ=0.8, 60 エポック)をどう結合しているかは両論文から読み取れない。ハード段階が各層の最終窓の後半 20% に限られるため、ハード状態での適応が不足している可能性。
2. **PPL と MC 精度の乖離**: PPL は 3 倍改善したが MC 精度は +1pt。論文 Appendix E(CAT-Q は数学/コードで崩壊し、キャリブレーションデータ生成戦略を変えた CAT-Q+ で大幅回復)が示すとおり、C4 キャリブレーションはタスク性能に対して弱く、論文の 51.01 との差の一部はデータ・評価周りの細部の可能性。
3. **LWC 相当の初期化/学習率**: リファレンスは lwc_lr=1e-2 (LM の δ に相当する学習率が我々の 1e-3×3 より大きい)。δ 学習率の引き上げは未検証。
4. 細部: huber 損失オプション、last_round_inp_num>1 の拡張、シード・C4 サンプリング差。

## 次のステップ候補

1. δ 因子の学習率を lwc_lr 相当 (1e-2) に上げた 0.6B での感度確認(2h/本)
2. Qwen3-4B での検証(論文 ablation の基準、CAT-Q avg 57.06。RTX 5090 でメモリ最適化済み実装なら実行可能な見込み)
3. ST 結合の代替案(パスごとに γ を適用しハード段階を各パス末尾に置く等)の ablation

## 追加実験: 二値化 (W1) モード

論文外の拡張として、三値の Δ→0 極限となる二値化 ({-1, +1} × グループスケール、`--quant-mode binary`) を実装した(プランは docs/plans/binary-quant-mode-plan.md)。soft は f_bin(Ŵ; s)=tanh(sŴ)/tanh(s)、hard は sign(0 は +1 に丸め)、δ_Δ 因子は作らず、μ が sign の決定境界(sign(Ŵ)=sign(W̃−μ))として学習される。ST スケジュール・フレームワーク・ハイパーパラメータは v3 の三値設定をそのまま流用。

### 結果 (512×2048、60 エポック、paper プロトコル)

| Model | #Bits | PIQA | ARC-e | ARC-c | HS | WG | Avg | C4-val PPL |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Qwen3-0.6B | W16A16 | 67.30 | 56.02 | 34.30 | 47.31 | 56.51 | **52.29** | 21.97 |
| + CAT-Q v3(三値、参考) | W1.58A16 | - | - | - | - | - | **37.07** | 87.6 |
| + CAT-Q 二値 | W1A16 | 56.26 | 31.19 | 21.76 | 27.23 | 50.91 | **37.47** | 111.6 |
| Qwen3-1.7B | W16A16 | 72.63 | 70.08 | 43.17 | 60.32 | 61.09 | **61.46** | 17.51 |
| + CAT-Q v3(三値、参考) | W1.58A16 | 61.97 | 41.33 | 24.83 | 36.92 | 52.01 | **43.41** | 38.8 |
| + CAT-Q 二値 | W1A16 | 57.89 | 34.55 | 22.27 | 29.51 | 50.36 | **38.91** | 87.15 |

### 所見

- 量子化時間は 0.6B: 90.6 分、1.7B: 212 分 / RTX 5090 ×1(三値の ~104 分 / ~234 分よりそれぞれやや短い。δ_Δ が無い分パラメータと ST 計算が軽い)。
- 最適化はどちらも健全: 全 38 窓で hard-init 比の loss 改善、焼き込み後の +1 率は 0.500(符号バランス良好、zero 率は定義上 0)。
- **0 レベル(グループ内疎性)の寄与はスケールを問わず PPL に明確に現れる**: 二値の PPL は三値比で 0.6B 1.3 倍(111.6 vs 87.6)、1.7B 2.2 倍(87.15 vs 38.8)。
- **MC 精度への現れ方はスケール依存**: 0.6B では両者ランダム近傍(35.0)で頭打ちのため同水準(37.47 vs 37.07)だが、判別力のある 1.7B では二値が三値に **−4.5pt**(38.91 vs 43.41)と明確に劣る。「PPL は MC 精度より鋭敏」という本レポートの観察と整合。
- 三値用にチューニングされたハイパーパラメータ(s₀=30、γ=0.8、lr)のままであり、二値固有のチューニング余地は残る。

## 追記（2026-09-28）: 現行の既定値（grad_clip = 0.5）での 0.6B 三値

[OutliersInLLM](https://github.com/takuma104/OutliersInLLM) の Phase 3 で、本実装を submodule として呼び出し、Qwen3-0.6B（post-trained）を現行の既定値で三値化した。キャリブレーションは v3 と同じキャッシュ（`calibration_ids.pt`、512×2048）で、`grad_clip` 以外の設定は v3 と同一。

| | C4-val PPL（本レポートの手順、8 文書） | 備考 |
| --- | --- | --- |
| FP | 21.96 | 本レポートの値 21.97 と一致 |
| v3 のモデル（`outputs/qwen3-0.6b-catq-v3`）を再評価 | 87.55 | 本レポートの値 87.6 と一致（評価手順の一致を確認） |
| **現行の既定値（`grad_clip = 0.5`）** | **46.3** | 量子化 116 分。窓の最終損失の合計 247（v3 は 337） |

- v3（`grad_clip = None`）の 87.6 から、**クリッピングだけで PPL が約半分になる**。
- 同じ実行を層ごとに診断すると、「診断で得た知見」に書いた回帰希釈（MA の振幅の縮小と、RMSNorm による方向誤差の増幅）は起きていない。MA の振幅は FP の 1.02 倍、Norm 後の相対誤差は Norm 前の 1.03 倍以内だった。回帰希釈は、クリッピングなしで最適化が不安定だったことの症状だった可能性がある。
- 二値化の行（0.6B で 111.6）が、どちらのクリッピング設定で得られたかはこのレポートに記録がない。三値との比較（「0 レベルの寄与」）は、設定をそろえて確かめ直す必要がある。
